# Breast Cancer Classification Model Comparison

## Problem Statement

This project compares five supervised classification algorithms for predicting
whether a breast tumour is benign or malignant. All models use the same
stratified 80/20 train/test split. `malignant` is treated as the positive class
for Precision, Recall, F1, and AUC.

## Dataset Description

The Breast Cancer Wisconsin Diagnostic dataset contains 569 observations and
30 numeric features computed from digitized images of breast mass samples. The
raw UCI file has an ID, a diagnosis label (`M` or `B`), and 30 numeric features.
The ID is excluded from training; diagnosis is mapped to malignant/benign. The
dataset has no missing values.

Source: [UCI Machine Learning Repository - Breast Cancer Wisconsin (Diagnostic)](https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic).
The provided `wdbc.data` and `wdbc.names` are included with the project.

## Run Locally

```bash
python -m pip install -r requirements.txt
python explore_dataset.py
python train_models.py
streamlit run app.py
```

The training script saves five fitted models and their comparison table under
`model/`, and saves the held-out labeled examples as `test_data.csv`. The app
accepts labeled CSV files to calculate evaluation metrics and unlabeled CSV
files to display predictions.
